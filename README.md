# Wirtualny Spacer 360° (Unreal Engine 5)

Interaktywny spacer po kampusie oparty na panoramach 360°, dynamicznym ładowaniu zasobów (`Soft Object References`), tabeli danych (`Data Table`) oraz płynnym przejściu kamery (`Camera Fade`).

## Sterowanie
* **Prawy Przycisk Myszy (przytrzymany) + ruch myszą:** rozglądanie się 360°
* **Lewy Przycisk Myszy / Spacja:** przejście do kolejnego punktu po najechaniu na strzałkę
